# Security and saved artifacts

For a vulnerability in the published repository, use GitHub's private vulnerability reporting feature if enabled. Otherwise contact the maintainers through a contact channel they have published; do not include exploit details or private data in a public issue. This project does not advertise a security response deadline or a guaranteed supported-version window.

Load legacy pickle checkpoints only from sources you trust. Unpickling executes Python object reconstruction; a matching hash does not establish that a file is trustworthy. The library also offers NPZ-based PyTree serialization. Predictor factories, plugins and Python model code should likewise be treated as executable input.

Report ordinary solver convergence and numerical accuracy problems with the bug template. Solver convergence and hard projection do not independently certify physical safety of a downstream application.
